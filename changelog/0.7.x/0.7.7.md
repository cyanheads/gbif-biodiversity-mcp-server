# 0.7.7 — 2026-10-24

## Changed

- **Read limits** clamp oversized page, facet, and contact requests with requested/applied notices; bulk matching processes 50 names and returns ordered `unprocessedNames`. Set `GBIF_CLAMP_READ_LIMITS=false` to restore rejecting maxima. ([#68](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/68))
- **Tool guidance** removes repeated measured examples while preserving filter rules and the occurrence partitioning recipe. ([#69](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/69))

## Fixed

- **Dataset record counts** disclose unavailable supplementary lookups through `recordCountNotice` while retaining metadata; cancellation, invalid responses, and caller-input errors propagate. ([#65](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/65))
- **Publisher text** decodes numeric references once and preserves paragraph breaks; dataset and species Markdown renders literal text consistently with structured output. ([#66](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/66))
- **Temporal coverage** preserves ranges, single dates, and verbatim periods on dataset tools and resources, with a notice for omitted unsupported entries. ([#67](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/67))
