# 0.7.6 — 2026-10-22

## Changed

- **Occurrence filters** now match across search, count and facets, with identical effective `scope` on both response surfaces; count retains `isGeoreferenced` as an alias for `hasCoordinate` and rejects conflicting pairs. ([#70](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/70))
- **Bun** 1.4.2 → 1.4.4 in package-manager and container pins; MCPB inputs exclude source, scripts, docs and editor metadata.
- **Release workflow** requires a separate review of each release PR before publishing.
- **Framework guidance**: `api-canvas` 2.7 → 2.8; `api-config` 1.25 → 1.26; `api-errors` 1.22 → 1.23; `api-telemetry` 1.20 → 1.21; `api-utils` 2.17 → 2.18; `field-test` 2.21 → 2.22; `git-wrapup` 1.29 → 1.30; `polish-docs-meta` 2.22 → 2.23; `security-pass` 1.12 → 1.13.

## Fixed

- **Species search** defaults explicitly to the GBIF backbone, preserves selected checklists, and exposes optional `datasetKey` and `nubKey` alongside the checklist usage `key` for occurrence chaining. ([#59](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/59))
- **Basis-of-record filters** accept all 11 GBIF values, adding `FOSSIL_SPECIMEN`, `OBSERVATION` and `UNKNOWN` so returned buckets can be searched. ([#60](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/60))
- **Species resource keys** decode once and validate the entire signed decimal identifier within GBIF's 32-bit range before fetching; valid plus, zero-padding and surrounding-whitespace aliases remain accepted. ([#61](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/61))
- **Pagination** uses one facet lookahead bucket to prove continuation, omits truncation on exactly full final pages, and gives offset-reset guidance for exhausted facet and child pages. ([#62](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/62))
- **Occurrence text** renders latitude, longitude and uncertainty independently with units, including zero values. ([#63](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/63))
- **Spatial guidance** states that geometry and coordinate ranges intersect, matching GBIF's existing filtering behavior. ([#64](https://github.com/cyanheads/gbif-biodiversity-mcp-server/issues/64))
